# [제안, 운영 미적용] 사건 작업 공간 저장

지금 앱의 사건 작업 공간(빠진 정보 답·사건 경위·증거 설명·일정·체크리스트)은 관리자 미리보기이며 **저장하지 않습니다**
(이 탭의 서버 메모리에만 있고 새로고침·로그아웃·계정 변경 시 사라짐). 초안 본문은 기존 `case_drafts`(적용됨, 기능은 꺼짐)를 씁니다.

- 이 제안은 `supabase/proposals/case_progress/`(체크리스트만)를 대신합니다. 하나만 적용하세요.
- **운영 DB에 적용하지 않았습니다.** 접근 제한·삭제 검사 스크립트 `supabase/tests/local_case_workspace_test.py`를 준비했지만,
  이 Mac에 Postgres가 없어 실행하지 못했습니다.

## 저장 항목과 크기 제한
| 열 | 내용 | 제한 |
|---|---|---|
| answers | 작업 공간에서 채운 빠진 정보(예: 장소 '모름') | 8KB |
| timeline | 사건 경위 줄(언제·무슨 일·관련 자료 이름) | 32KB |
| evidence_notes | 자료 이름·무엇을 보여 주는지·출처(파일 내용 아님) | 16KB |
| schedules | 사용자가 정한 일정(종류·제목·날짜·시간·알림 분·메모) | 16KB |
| checklist | 준비 체크·제출한 곳·제출일·메모 | 2KB |

## 앱에 붙일 때(결정 후)
- 저장 버튼 하나로 묶고 '저장 중 / 저장됨(시각) / 저장 실패(수정 내용 유지) / 저장하지 않은 수정 있음'을 표시
- 저장 실패 시 화면 값은 그대로 두고 다시 저장 가능
- 사건 수정은 지금 앱에 없으므로(cases는 insert/delete만), 빠진 정보 답은 answers에만 두고 초안에 반영

## 방침 문구안(새 버전에 추가)
- 처리 항목: "사건 정리 기능 이용 시: 이용자가 직접 정리한 사건 경위, 증거자료 설명, 일정(날짜·시간·메모), 준비 체크 기록"
- 보유 기간: "사건을 삭제하거나 회원탈퇴할 때까지(사건 삭제 시 함께 삭제)"

## 적용 순서
1. `LOCAL_PG=... python3 supabase/tests/local_case_workspace_test.py`
2. 방침 개정·시행일 → 운영자 승인 후 SQL 적용 → 앱 저장 코드(플래그로 끈 채 배포 → 관리자 시험)
