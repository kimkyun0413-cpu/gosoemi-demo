# [제안, 운영 미적용] 사건 진행 체크리스트 저장

지금 앱의 체크리스트는 관리자 미리보기이며 **저장하지 않습니다**(이 탭의 서버 메모리에만 있고 새로고침·로그아웃 시 사라짐).
저장하려면 이 폴더의 SQL을 적용해야 하며, **운영 DB에 적용하지 않았습니다.** 접근 제한·삭제 검사는
`supabase/tests/local_case_progress_test.py`(로컬 임시 Postgres 전용)로 준비했지만, 이 Mac에 Postgres가 없어 아직 실행하지 않았습니다.

## 저장 항목
경위 정리·증거 준비·초안 생성·초안 확인·전문가 검토·제출 여부(체크), 제출한 곳(60자), 제출일, 다음 할 일 메모(300자)

## 적용 전에 정할 것
1. 저장 기능을 켤지(켜지 않아도 미리보기처럼 화면에서만 쓸 수 있음)
2. 개인정보처리방침 새 버전에 아래 문구 추가와 시행일

## 방침 문구안
- 처리 항목: "사건 진행 체크리스트 이용 시: 이용자가 직접 표시한 준비 항목, 제출한 곳·제출일, 다음 할 일 메모"
- 보유 기간: "사건을 삭제하거나 회원탈퇴할 때까지(사건을 지우면 함께 삭제)"
- 국외 이전 표 Supabase 항목은 '서비스 이용 중 처리되는 정보'에 포함

## 적용 순서(결정 후)
1. `LOCAL_PG=... python3 supabase/tests/local_case_progress_test.py`로 로컬 검사
2. 방침 개정·시행일 확정 → 운영자 승인 후 SQL 적용 → 앱 저장 코드 추가(플래그로 끈 채 배포 → 관리자 시험)
