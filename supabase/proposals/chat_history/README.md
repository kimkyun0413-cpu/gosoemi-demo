# [제안, 운영 미적용] AI 상담 대화 저장·다시 열기

지금 앱은 대화를 DB에 저장하지 않습니다(서버 메모리에만 두고, 새 대화·지우기·로그아웃·계정 변경 시 즉시, 새로고침·탭 닫기 후 약 2분 뒤 정리).
이 폴더는 운영자가 "이전 대화 다시 열기"를 원할 때를 위한 준비물입니다. **운영 DB에 적용하지 않았고, 로컬 Postgres 검사도 아직 하지 않았습니다**(이 Mac에 Postgres 없음).

## 파일
- `20261010000000_chat_history.sql` — 대화·메시지 표, 본인만 접근(RLS), 탈퇴 시 함께 삭제, 이용자당 50개 상한, 보관 기간(기본 30일) 지난 대화 삭제 함수
- `20261010000000_chat_history_rollback.sql` — 되돌리기(저장된 대화 전부 삭제)

## 적용 전에 정할 것
1. 저장을 기본으로 할지, 이용자가 '이 대화 저장'을 눌렀을 때만 할지 (추천: 누를 때만)
2. 보관 기간(추천안 30일)과 만료 대화 삭제 실행 방법(pg_cron 또는 앱에서 열 때 삭제)
3. 개인정보처리방침 개정과 시행일(아래 문구안), 재동의 방식

## 방침 문구안 (v3 이후 새 버전에 추가)
- 처리 항목: "AI 상담 대화 저장 이용 시: 이용자가 '대화 저장'을 눌러 저장한 대화의 질문·답변 글과 저장 일시. 음성은 저장하지 않습니다."
- 보유 기간: "저장한 대화: 저장한 날부터 30일 또는 이용자가 삭제하거나 회원탈퇴할 때까지 중 먼저 도래하는 때"
- 파기: "보유 기간이 지난 대화는 지체 없이 삭제합니다."
- 위탁·국외 이전 표의 Supabase 이전 항목에 "저장한 AI 상담 대화" 추가

## 적용 순서(결정 후)
1. 로컬 임시 Postgres에서 RLS·탈퇴 삭제·상한 검사 (`supabase/tests/local_case_drafts_test.py`와 같은 방식)
2. 방침 새 버전 작성·검토 → 시행일 확정
3. 운영자 승인 후 SQL 적용, 앱 코드 추가(기능 플래그로 끈 채 배포 → 관리자 시험 → 시행일에 켜기)
