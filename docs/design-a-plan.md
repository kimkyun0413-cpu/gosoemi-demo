# A안 화면 구현 계획 (2026-10-23 운영자 확정)

브랜치 `feat/design-a`. 운영 반영 전에 맥북·휴대폰 실제 화면, 기존 자료 보존, 검사 결과를 운영자에게 먼저 보여 준다.
시안 이미지: 바탕화면 `고소미_화면시안/A안_최종`, `고소미_화면시안/후기_시안`.

## 확정 사항
- 메뉴: 맥북(넓은 화면)은 왼쪽 고정 메뉴, 휴대폰은 아래 고정 메뉴(홈·내 사건·작성·상담·검색). 내 계정은 왼쪽 메뉴 맨 아래, 휴대폰은 위쪽 오른쪽.
- 사건은 4단계: 사건 내용 → 증거 → 고소장 초안 → 내려받기. 일정·제출 준비는 사건 화면 아래 링크로.
- 단계 완료 표시 = **이용자가 그 단계 정리를 마쳤다고 표시한 것**. 증거가 충분하다거나 제출 준비가 끝났다는 뜻이 아니라고 화면에 적는다.
- 새 사건은 4단계 입력(피해 유형 → 무슨 일 → 상대방·증거 → 확인·저장).
- '직접 채울 곳'([확인 필요])은 접고 펼칠 수 있게(처음엔 접힘).
- 초안 '문장 다듬기'(사실·금액·날짜 유지, 문장만)와 '새로 만들기'(저장한 사건 내용으로 처음부터) 차이를 버튼 옆에 쉬운 말로.
- 새로 만들기 전에 지금 초안(직접 고친 내용 포함)을 '이전 초안'으로 보관하고 새로고침·재로그인 뒤에도 되돌릴 수 있게 → **DB 변경 필요**(아래).
- 휴대폰 키보드가 올라와도 입력칸·저장 버튼이 가려지지 않게(입력 중에는 아래 메뉴를 숨김). iOS 시뮬레이터 Safari로 확인.
- 기존 사건·증거파일·수정한 초안 보존(화면만 바꾸고 데이터 구조는 그대로. 새 표·열은 추가만).
- 법령 API는 보류(`feat/law-open-api`). 검색 메뉴는 국가법령정보센터 공식 검색으로 연결하는 지금 상태로 표시.
- 이용 후기: 첫 화면 아래 공개 후기 + '후기 더 보기', 내려받은 뒤 선택 안내, 별점·도움이 된 점·개선할 점, '운영자에게만'/'익명 공개' 선택,
  공개는 운영자 확인 뒤 게시, 작성자 수정·삭제(공개 후기를 고치면 다시 확인 대기), 개인정보·사건 내용 넣지 말라는 안내, 실제 후기가 없으면 빈 화면(가짜 후기 금지).

## 진행 상황 (2026-10-23)
- 1~6단계 코드 완료(브랜치 커밋). 자동 테스트 274개 통과.
- 운영 미적용 DB 변경 2개: `20261023000000_case_draft_archive`(이전 초안 보관), `20261023000001_service_reviews`(이용 후기).
  각각 되돌리기 SQL과 로컬 Postgres 시험(`supabase/tests/local_case_draft_archive_test.py`, `local_service_reviews_test.py`) 준비.
  적용 전에는 `DRAFT_ARCHIVE_ENABLED`, `REVIEWS_ENABLED`를 켜지 않는다(꺼져 있으면 '새로 만들기'는 준비 중 안내, 후기 영역은 숨김).
- 후기 운영자 지정: 마이그레이션 적용 뒤 SQL Editor에서 `insert into public.review_admins values ('<운영자 user id>');`
- 남은 것: 7단계(맥북·휴대폰 실제 화면, iOS 시뮬레이터 키보드, 로컬 DB 시험 실행, 기존 자료 보존 확인).

## 단계 (각 단계마다 테스트 추가, 커밋)
1. 메뉴 틀과 첫 화면: 왼쪽/아래 고정 메뉴, 첫 화면(새 사건 카드·이어서 하기·기능 칸), 검색 화면(공식 사이트 연결), 키보드 대응 CSS.
2. 내 사건 목록: 상태 거르기, 사건별 4단계 표시(이용자 표시 기준), 다음 할 일 버튼.
3. 사건 화면 4단계: 단계 표시와 '정리 마침' 표시(작업 공간 checklist에 저장, DB 변경 없음), 채울 곳 접기, 초안 바꾸기 설명.
4. 새 사건 단계별 입력.
5. 이전 초안 보관(DB): `case_drafts`에 이전 초안 열 추가 또는 보관 표 — 마이그레이션·되돌리기 SQL 준비, **운영 적용은 운영자 승인 후**. 적용 전에는 기능을 끈다.
6. 이용 후기(DB): 후기 표·RLS(본인 작성·수정·삭제, 게시된 것만 공개 조회, 운영자 검토), 개인정보처리방침 v3에 후기 항목 추가.
   **새 개인정보 수집이므로 방침에 적은 버전이 시행되기 전에는 관리자만**(CLAUDE.md 규칙). 운영 적용은 운영자 승인 후.
7. 운영 반영 전 확인: 맥북 브라우저·iOS 시뮬레이터 화면, 기존 자료(시험 계정) 그대로인지, 전체 테스트.

## 주의
- 사건 작업 공간(4단계 화면의 바탕)은 지금 관리자에게만 보인다(`ASSIST_V2_ENABLED`, 방침 v3 시행 전). 일반 이용자 공개 시점은 기존 규칙을 따른다.
- 운영 DB·Supabase 정책·Streamlit 설정 변경은 운영자 승인 없이 하지 않는다.
