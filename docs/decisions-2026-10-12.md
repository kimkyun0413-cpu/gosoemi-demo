  이 모델은 운영 앱만 호출하므로, 운영 키(이름 `gosoemi-streamlit`)는 이 프로젝트의 키입니다.
- 이 프로젝트에는 결제 계정이 연결되어 있지 않고, 운영 로그의 Google 오류 문구도 "on Free Tier"였습니다 → **무료 등급**.
- 무료 등급 약관(Gemini API 추가 약관 'Unpaid Services'): 입력·응답을 Google 제품 개선에 쓰고, **사람 검토자가 읽을 수 있으며**,
  "민감·기밀·개인정보를 보내지 말라"고 정합니다. 유료 등급은 제품 개선에 쓰지 않습니다.

### 3. Gemini 이용 연령 조건
- Gemini API 추가 약관 'Age Requirements'(2026-04-28): API 이용자는 18세 이상, **18세 미만이 대상이거나 이용할 가능성이 높은 서비스에서 쓰지 않는다**.
  적용 범위는 Gemini API 전체 → 고소미의 AI 상담·초안·음성 받아쓰기·입력칸 정리·요약·표현 바꾸기·서버 목소리 **모두 해당**.
- Google Cloud(Vertex AI) 서비스 약관 20(d)도 같은 내용 → 옮겨도 해결되지 않음. 위반이 의심되면 바로 중지될 수 있음(20(f)).

### 4. 메일 인증·비밀번호 찾기 — **이메일 가입이 일반 이용자에게 사실상 막혀 있음**
- 운영 Supabase: 새 가입 허용, **'Confirm email'(이메일 인증) 켜짐**, 직접 메일 서버(SMTP) 없음 → Supabase 기본 메일 사용.
- Supabase 공식 문서: 기본 메일은 **프로젝트 팀원 주소로만 보내고**(그 밖의 주소는 거부), 시간당 2통, 운영용 아님.
- 그래서 일반 이용자가 이메일로 가입하면 인증 메일을 받지 못해 로그인할 수 없습니다. 네이버·Google 로그인은 영향 없음.
- 비밀번호 찾기는 꺼져 있음(`PASSWORD_RESET_ENABLED`). 메일 서버가 있어야 켤 수 있음.
- 이번에 한 일: 메일을 못 보낼 때 "네이버 또는 Google로 가입해 주세요"라고 알리도록 고침. 운영자가 이메일 가입만 잠시 닫을 수 있는
  `EMAIL_SIGNUP_ENABLED` 설정 추가(설정이 없으면 지금처럼 열림 — 운영 설정은 바꾸지 않음).

### 5. 백업·복구 — **스크립트 오류 2개 발견·수정**
- 로컬 임시 DB에서 백업 → 새 DB에 복구까지 처음으로 실제 실행(`supabase/tests/local_backup_restore_test.py`, 17/17 통과).
- 발견 1: 백업 스크립트가 **계정 표만 담고 사건·초안·동의·네이버 연결 자료를 빠뜨림**(pg_dump는 `--table`을 쓰면 `--schema`를 무시). 운영에서 실행한 적이 없어 불완전한 백업은 없음. 고침.
- 발견 2: 복구가 'public 스키마가 이미 있음'으로 첫 줄에서 멈춤(새 Supabase 프로젝트에는 public이 있음). 고침(예전 백업 파일에도 적용).
- 확인: 행 수 일치, 계정-사건 연결, 본인만 보는 정책 유지, 틀린 암호·운영 주소로는 복구하지 않음, 백업 파일에 자료가 평문으로 보이지 않음.
- 아직: 운영 DB에서 실제 백업, 새 Supabase 프로젝트에 복구 연습(실제 auth 표 구조로), 증거파일 백업 실행.

### 6. 결제 준비 — 변화 없음
- 판매 꺼짐(`BILLING_MODE` 없음 = off). DB·Edge Function 안은 적용 안 함. 웹훅 처리 테스트 8개 통과(오늘 다시 실행).
- 사업자등록·통신판매업 신고·결제사 계약 전에는 진행할 것 없음.

### 7. 운영 설정에 쓰이지 않는 비밀값
- `SUPABASE_SECRET_KEY`: IP 전달 설정이 꺼져 있어 지금 코드에서 쓰지 않음(전체 권한 키라 두지 않는 편이 안전).
- `APP_PASSWORD`: 지금 코드 어디에서도 쓰지 않음(예전 설정으로 보임).

## 결정할 것 (중요한 순서)

### A. Gemini를 유료 등급으로 바꿀지 — **추천: 출시 전에 바꾸기**
- 이유: 지금은 사건·상담 내용이 Google 제품 개선·사람 검토 대상이 될 수 있고, 시행 중인 방침과 다릅니다. 약관도 무료 등급에 개인정보를 보내지 말라고 합니다.
- 비용: 쓴 만큼(공식 가격표). 글 답변 모델 `gemini-3.5-flash-lite` 입력 100만 토큰당 $0.30·출력 $2.50 → 상담 한 번 주고받기 약 $0.001~0.002.
  서버 목소리 10초 $0.0015(2026년 말까지, 이후 $0.003). 예산 알림을 걸 수 있지만 알림은 요금을 막지 않습니다.
- 해 주실 일: ① Google Cloud에서 'Default Gemini Project'에 결제 계정 연결 ② 예산 알림 설정(예: 월 $10) ③ AI Studio에서 등급이 바뀐 것 확인.
  그 전까지 운영을 계속한다면 ④ 방침에 실제(무료 등급)를 적는 새 버전과 이용자 안내가 필요한지 전문가 확인(검토 자료 질문 14).
- 바꾸지 않으면: 방침 1번 차이가 계속되고, 서버 목소리는 하루 10번 한도.

### B. Gemini 연령 조건 — **추천: 가입 연령을 만 18세 이상으로 올리기**
- 이유: Gemini를 쓰는 기능 모두가 약관의 '18세 미만이 이용할 가능성' 조건에 걸립니다. 다른 방법(14~17세만 AI 끄기)은 나이를 더 받아야 하고 조건이 남습니다.
- 비용: 돈은 들지 않음. 개발(약관·방침 새 버전, 가입·소셜 로그인 나이 확인 문구, 기존 계정 재확인 화면)과 법률 검토가 필요.
- 기존 14~17세 계정: 지금은 '만 14세 이상' 확인만 받아 나이를 모릅니다. 다음 로그인 때 '만 18세 이상' 확인을 받고, 아니라고 하면 AI 기능을 막고 탈퇴·자료 내려받기를 안내하는 안을 추천.
- 해 주실 일: 18세로 올릴지 결정 → 정하시면 제가 약관·방침 새 버전과 화면을 준비(시행일·공개는 운영자 승인 후).

### C. 메일 서버 연결 — **추천: 도메인 구입 + Resend 무료**(2026-10-06 안과 같음)
- 이유: 지금 일반 이용자는 이메일 가입을 마칠 수 없습니다. 비밀번호 찾기도 메일이 있어야 켤 수 있습니다.
- 비용: 도메인 연 사용료(등록업체마다 다름). Resend 무료(월 3,000통·일 100통, 공식 페이지).
- 해 주실 일: ① 도메인 구입 ② Resend 가입·도메인 인증(제가 화면 안내) ③ Supabase SMTP 설정(승인하시면 제가 입력 도움, 키는 직접 붙여 넣기).
- 그 전까지: Streamlit Secrets에 `EMAIL_SIGNUP_ENABLED = "false"`를 넣어 이메일 가입만 잠시 닫고 네이버·Google 가입으로 안내하는 것을 추천(비용 없음, 이미 가입한 이메일 계정 로그인은 그대로).

### D. 백업 시작 — **추천: 출시 전 복구 연습 1회, 이후 주 1회·최근 4주 보관**
- 비용: 없음(Free 플랜, 새 무료 프로젝트로 연습 가능). 이 Mac에 PostgreSQL 클라이언트 설치 필요(`brew install libpq`, Homebrew가 없으면 공식 배포판).
- 해 주실 일: 시작 여부·주기·보관 기간 결정, 백업 암호 보관 방법 정하기. 정하시면 제가 순서대로 안내(운영 DB 비밀번호는 직접 입력).

### E. 쓰이지 않는 비밀값 정리 — **추천: 지우기**
