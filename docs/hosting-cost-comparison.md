# 서버 후보·예상 비용 비교 (2026-10-13, 결정·결제·변경 없음)

> 비교와 준비만 했습니다. 결제, DNS, 로그인 주소, 운영 설정, 기존 이용자 자료는 그대로입니다. Render 월 $25안은 확정하지 않은 상태입니다.
> 가격은 2026-10-13에 각 회사 공식 페이지에서 확인한 미국 달러 기준이고, 바뀔 수 있습니다. 원화는 **1달러 = 1,400원으로 가정**해 어림한 값입니다.

## 1. Streamlit 약관이 무료 시험 운영에도 해당하는가
**조항:** [Streamlit Terms of use](https://streamlit.io/terms-of-use)(Last updated: November 2025) → "Addendum: Community Cloud Content" → **4. Prohibition on Processing of Personal Information.** 두 문장입니다.

| 문장 | 원문 핵심 | 무료 시험 운영에 해당? |
|---|---|---|
| 첫째 | 개인정보를 처리하는 경우 "personal and non-commercial purposes, such as evaluation, educational, or household use"로만 쓸 수 있고, "for the benefit of, or otherwise in connection with, a business or commercial purpose"로는 쓸 수 없음 | **해당할 가능성이 높음.** 돈을 받지 않아도, 유료 판매를 준비하는 서비스의 시험 운영은 '사업과 관련된(in connection with)' 사용으로 볼 여지가 큽니다. 약관에 'business'의 정의는 없습니다 |
| 둘째 | "heightened legal or regulatory data protection requirements"가 있는 내용, 예를 들어 "financial information, health information, biometric information, and any other sensitive personal information"을 처리하면 안 됨 | **유료 여부와 관계없이 적용.** 이용자가 피해 사실(다친 내용·성범죄 피해 등)을 적을 수 있어 민감한 정보가 들어올 수 있습니다 |

- 결론(제 해석, 법률 판단 아님): **무료 시험도 이 조항에 걸릴 위험이 높습니다.** 유료 판매 직전이 아니라, **일반 이용자를 더 받기 전에** 서버를 옮기는 것이 안전합니다. 전문가 검토 자료 부록 A8에 같은 질문을 넣었습니다.
- 지금 할 수 있는 위험 줄이기(설정 변경 없음): 새 이메일 가입이 이미 멈춰 있고, AI도 멈춰 있습니다. 서버를 옮기기 전까지 일반 이용자 모집을 늘리지 않는 것을 추천합니다.

## 2. '내 자료 모두 내려받기'의 메모리 — 낮은 요금제가 가능한가

**측정**(가짜 자료, 이 맥에서 실제 앱 코드 실행 — 운영 접속 없음):
| 상황 | 측정값 |
|---|---|
| 앱만 불러온 상태 | 약 150MB (실제 서버는 웹 서버·접속자 몫이 더해져 이보다 큼 — **미측정**) |
| 증거파일 50MB 내려받기 준비 | 약 +75MB |
| 증거파일 200MB(현재 상한) 내려받기 준비 | 약 +225MB (원본 파일 + ZIP 묶음이 동시에 메모리에 있음) |

**왜 큰가:** 지금은 ① 모든 증거파일을 한꺼번에 메모리로 받고 ② 모든 ZIP 묶음(약 40MB씩)을 한꺼번에 만들어 ③ 화면의 내려받기 버튼마다 한 벌씩 들고 있으며 ④ '준비한 파일 지우기'를 누르기 전까지 그 접속자의 화면 상태에 남습니다. 실제 서버에서는 ③ 때문에 더 커질 수 있습니다.

**줄이는 방법(코드 변경안, 아직 적용 안 함):**
1. 글 자료(사건·초안·사건 정리·동의 기록)만 담은 1번 묶음은 지금처럼 바로 만들기(보통 수백 KB 이하)
2. 증거파일은 **'2번 묶음 만들기' 버튼을 누를 때 하나씩**, 묶음당 약 20MB로 만들고 앞 묶음은 메모리에서 지움
3. 내려받은 뒤 화면 상태에 남기지 않음
- 예상 효과: 내려받기 중 추가 메모리 **약 +225MB → 약 +60MB 이하**(20MB 묶음 × 원본·ZIP·버튼). 동시에 여러 명이 받아도 1인당 이 정도
- 단점: 증거파일이 많은 사람은 버튼을 여러 번 눌러야 함
- 확인 못 한 것: 실제 서버(웹 서버 포함)의 기본 메모리, 여러 명이 동시에 쓸 때 — **옮길 서버에서 시험 후 확정**

**판단:**
| 메모리 | 지금 코드 | 위 변경 후 |
|---|---|---|
| 512MB | 큰 내려받기 1건이면 넘칠 수 있음 → **불가** | 소규모 시험은 **가능할 것으로 보임**(미검증). 음성 업로드·동시 접속이 겹치면 빠듯 |
| 1GB | 1명은 가능, 동시 2명 이상 위험 | **소규모 시험·초기 유료 운영에 적당** |
| 2GB | 여유 | 여유(접속자가 많아지면) |

**추천**
- **소규모 시험:** ① 메모리 줄이기 변경 → ② **Fly.io 도쿄 1GB(약 $8.8/월)** 또는 서버 관리를 감수하면 **Lightsail 서울 1GB($7/월)**. 512MB(약 $4.8)도 변경 후 시험해 보고 충분하면 그대로 써도 됩니다.
- **실제 유료 운영:** 같은 곳에서 1GB로 시작, 접속자가 늘면 2GB(Fly 약 $16.6 / Lightsail $12)로 올림.
- 운영자 혼자 관리한다면 **Fly.io**(서버 관리 부담 적음), 비용·서울 위치가 더 중요하면 **Lightsail 서울**.
- 어느 쪽이든 방침의 위탁·국외 이전 표에서 Streamlit(Snowflake, 미국)을 새 업체로 바꾸고 시행 절차를 거쳐야 합니다(Lightsail 서울이면 서버는 국내).

**AI 비용 계산(어림):** 공식 단가 입력 100만 토큰당 $0.30, 출력(생각 포함) $2.50 ([Gemini 요금](https://ai.google.dev/gemini-api/docs/pricing)). 상담 1회(입력 약 3천·출력 약 1천 토큰) ≈ $0.003, 초안 1건(입력 약 4천·출력 약 3천) ≈ $0.009. 300명 × 30회 × $0.003~0.008 ≈ **$27~70/월**. 실제 토큰 수는 **측정하지 않은 추정**이고 '생각' 토큰이 많으면 올라갑니다. 앱의 시간당 호출 제한(`AI_CALLS_PER_HOUR`, `AI_CALLS_PER_HOUR_TOTAL`)과 Google Cloud 예산 알림으로 상한을 둘 수 있습니다.

**포함하지 않은 것(확인 못 함):** 결제대행 수수료(판매액의 일정 %, 결제사 미정), 사업자등록·통신판매업 신고 비용, 세금, 환율 변동, 업무 메일함 요금, 도메인 정확한 가격.

## 5. 다음 순서 (모두 운영자 승인 후)
1. 전문가 답변(부록 A8 포함) 확인
2. 서버 업체 결정(Fly.io / Lightsail 서울) → Claude가 '내 자료 모두 내려받기' 메모리 줄이기 변경 + 배포 설정 파일 준비, 로컬에서 메모리 측정
3. 방침 위탁·국외 이전 표 수정(서버·메일 업체) → 검토·시행 절차
4. 새 서버에 시험 배포(시험 계정만, 기존 이용자 자료는 Supabase에 그대로 — 옮기지 않음) → 도메인 연결 → 로그인 주소 변경(승인 후) → 전환
