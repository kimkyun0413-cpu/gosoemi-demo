## 새 AI 대화·음성 대화 (2026-10-10 개편, 관리자 시험 모드에서만 보임)
- 화면: 'AI 상담' 탭. 관리자에게는 새 화면이, 일반 이용자에게는 기존 화면이 보임
- **글 채팅**: 대화 내용이 가운데, 아래에 입력창과 그 옆 둥근 음성 버튼. 새 대화·대화 지우기·사건 정보로 정리하기·자세한 안내는 오른쪽 위 '메뉴' 안에 둠. 같은 대화의 이전 질문·답변(최근 20개)을 함께 보내 후속 질문에 반영. 답변 중 입력 잠금, 10초 안 같은 질문 중복 방지, 실패 시 질문을 남겨 고쳐서 다시 보내기
- **음성 대화**(음성 버튼 → 별도 화면): 큰 마이크 버튼을 누르면 그때 마이크 권한을 묻고 듣기 시작 → 말이 끝나고 1.3초 조용하면 자동 전송 → 서버가 글로 바꾸고(기존 Gemini 받아쓰기) 답변 → 기기 음성으로 읽기 → 다시 듣기. 매번 누를 버튼 없음
  - 상태 표시: 듣는 중 / 생각 중 / 답변 중 / 마이크 꺼짐. 버튼: 마이크 끄기, 답변 정지, 대화 종료, 글 채팅으로
  - AI 목소리 재입력 방지: 답변을 읽는 동안과 생각하는 동안 마이크 트랙을 끔(+브라우저 에코 제거). 다시 켠 직후 0.3초는 버림
  - 실패 안내: 못 알아들으면 "다시 말씀해 주세요" 후 계속 듣기, 답변 실패 시 다시 말하거나 글 채팅에서 고쳐 보내기, 마이크 권한 거부·미지원 시 글 채팅 안내. 45초 동안 말이 없으면 마이크를 끔. 한 번에 최대 40초
  - 같은 대화 기록을 쓰므로 글↔음성을 바꿔도 이어짐. 인식된 글과 답변 전문은 '인식된 글과 답변 보기'에서 펼쳐 봄
  - 종료·화면 이동·로그아웃·탭 닫기 시 마이크 트랙 정지와 읽기 취소(브라우저 부품의 정리 함수, pagehide)
  - 구조: Streamlit 기존 녹음 위젯 대신 앱에 들어 있는 브라우저 부품(`st.components.v2`, 새 서비스·키 없음)이 Web Audio로 소리 크기를 보고 말 끝을 판단, 그 부분만 16kHz WAV로 서버에 보냄. 녹음은 업로드 저장소·임시파일을 거치지 않고 요청 처리 중 메모리에만 있음
  - 남은 제약: 반이중(AI가 말하는 중에는 끼어들 수 없음, '답변 정지' 또는 마이크 버튼으로 끊고 말하기). 소리 크기 기준이라 시끄러운 곳에서는 말 끝을 늦게 알아챌 수 있음. 전화처럼 실시간으로 끼어드는 대화는 추후 기능
- 답변 읽기: 브라우저 내장 음성 중 **기기 안 한국어 음성(`localService`)만** 사용 → 추가 비용·새 서비스·키 없음, 답변 글을 외부 음성 서버로 보내지 않음. 기기에 한국어 음성이 없으면 답변을 글로 보여 줌
  - 선택 이유: Gemini TTS(`gemini-3.8-flash-lite-tts`, 한국어 지원)는 오디오 출력 100만 토큰당 $6(2027-01-01부터 $12)이고 답변 글을 Google에 한 번 더 보냄. 일부 데스크톱 Chrome의 'Google 한국의' 같은 원격 음성은 글이 외부로 갈 수 있어 제외
  - 기기별 차이: macOS(이 Mac의 앱 내 브라우저)에서는 '유나' 등 기기 안 한국어 음성 9개 확인. Chrome은 사용자가 페이지를 한 번 이상 누른 뒤에만 읽기를 허용(M71~). iPhone Safari는 마이크 버튼을 누를 때 소리 재생을 미리 깨워 두도록 처리했으나 실기기 미확인
- 사건 정보 정리(메뉴): 이용자 발언만(AI 답변 제외) 정리 → 항목별 체크·수정 → '고소장 작성' 탭 입력칸에 넣기. 이미 적은 칸은 기본 해제+경고, 사건 자동 저장 없음
- 법률 답변 원칙(지시문): 사실·추측 구분, 범죄 성립·승소·처벌 단정 금지, 확인 안 된 판례·법조문·기한 금지, 검색하지 않으므로 '최신 정보 확인' 표현 금지, 위험하면 112 먼저. 음성 대화에서는 2~4문장으로 짧게
- 대화 보관: DB 저장 없음. 서버 메모리에만 있고 새 대화·지우기·로그아웃·계정 변경 시 즉시 삭제. 새로고침·탭 닫기 시 화면에서 바로 사라지고, 서버 메모리는 연결이 끊긴 뒤 약 2분 뒤 정리(Streamlit `server.disconnectedSessionTTL` 기본 120초). Google 보관(55일 안내)은 앱이 지울 수 없음을 화면·방침에 구분해 적음
- 비용·제한(공식 가격표 기준, 유료 등급): 받아쓰기·답변·정리 모두 기존 `gemini-3.5-flash-lite`(입력 100만 토큰당 $0.30, 출력 $2.50). 음성은 1초에 32토큰(10초 말하기 ≈ 320토큰 ≈ $0.0001). 한 번 주고받기는 대략 $0.001~0.002. 답변 읽기는 기기에서 처리해 비용 없음. 기존 계정당 1시간 30회·전체 300회 제한과 90초 시간 초과를 그대로 적용(음성 한 번 = 받아쓰기+답변 2회로 셈 → 음성만 쓰면 1시간에 약 15번 주고받기)
- 운영자 시험 절차: 위 '남은 일' 15번
- **운영 앱 실제 시험 결과(2026-10-10, 운영자 확인, 관리자 시험 모드)**: 실제 목소리와 실제 Gemini로
  - 말한 뒤 자동으로 전송되고 음성 답변이 나옴
  - 답변 뒤 버튼을 누르지 않고 다음 질문으로 이어짐
  - 앞서 말한 '노트북, 45만 원'을 기억해서 답함
  - '대화 종료' 정상 동작
  - 시험 기기: 맥북. 브라우저 종류는 기록되지 않음(미확인). iPhone·Android 동작은 미확인
  - 확인하지 않은 것: 다른 기기 종류, 스피커로 나온 AI 목소리의 재입력 여부(이번 기록에 포함되지 않음), 시끄러운 곳, 답변 내용의 법률적 정확성

## 보조 기능 (2026-10-10, 관리자 시험 모드에서만 보임)
- **법률 용어 풀이**: 20개 용어를 쉬운 말과 짧은 예시로(기존 9개 + 고소장·불송치·이의신청·혐의없음·기소유예·공소권없음·약식명령·합의·형사조정·배상명령·무고죄). 뜻은 대검찰청 사건처리절차 안내 기준, 기한은 적지 않음. '법률 용어' 탭(검색), 사건 작성 화면·초안 화면(관련 용어만 펼쳐 보기), AI 상담 메뉴('용어 풀이')
- **피해 유형별 Q&A**: 14개 유형 모두 기존 Q&A에 '준비할 자료', '상대방을 모를 때', '확인할 절차·꼭 고소해야 하나요'를 빠진 것만 보탬(이미 확인한 유형별 안내·공식 링크로만 구성, 새 법률 사실 없음). 절차 구분 표시 [형사]·[형사 + 다른 절차]·[민사]·[노동]. "모든 피해가 고소 대상인 것은 아니"라고 안내
- **사건 진행 체크리스트**: '내 사건'의 사건마다 경위 정리·증거 준비·초안·사실 확인·전문가 검토(선택)·제출 여부, 제출한 곳·날짜, 다음 할 일 메모. "직접 표시하는 기록이며 경찰·법원 진행 조회가 아님" 안내. 지금은 저장하지 않는 미리보기(탭 서버 메모리, 계정 전환·로그아웃 시 삭제). 저장안: `supabase/proposals/case_progress/`(본인만 접근, 사건·탈퇴 시 삭제) + `supabase/tests/local_case_progress_test.py`(로컬 Postgres 없음 → 미실행)
- **핵심만 보기**: AI 상담 글 채팅의 300자 이상 답변 아래 버튼 → '핵심 / 다음에 할 일'로 요약(추가 AI 호출 1회, 기존 사용량 제한·시간 초과 적용). 원래 답변에 없는 숫자가 들어가면 보여 주지 않음
- **판례 찾기**: 앱이 판례를 검색·생성하지 않음. '피해 유형별 안내' 탭에서 국가법령정보센터 판례 검색 화면으로 연결(새 창, 외부 사이트라고 표시) + 붙여 넣을 검색어 예시. 검색 페이지 주소에 검색어를 붙여도 검색되지 않음을 확인(2026-10-10)해 페이지만 연결
  - 법제처 국가법령정보 Open API(판례 목록 `lawSearch.do?target=prec`)는 회원가입·사용 신청·서버 IP 등록 필요 → 연결 코드만 준비(`precedent_search.py`, `LAW_OPEN_API_OC`가 있을 때만 동작, 실제 조회된 사건명·사건번호·선고일자·법원명과 출처만 표시). 가짜 응답으로만 시험
  - 대법원 종합법률정보는 이 Mac의 앱 내 브라우저에서 열리지 않아 링크하지 않음
- **초안 안내 정리(모든 이용자)**: 초안 화면 안내와 문서 끝 문구를 "AI가 만든 참고용 초안입니다. 제출 전 사실관계와 내용을 직접 확인하고, 법률 전문가의 검토를 받아 주세요."로 통일. 이용자가 문구를 지워도 TXT·Word로 내려받을 때 한 번 붙음(예전 문구가 있으면 중복하지 않음). 편집 요령은 입력칸 도움말로 옮김
- 변호사 연결: 계약·제휴가 없어 만들지 않음(추후 과제). 상담 안내는 기존 대한법률구조공단(132) 링크 유지
- 개인정보: '핵심만 보기'(답변 글을 Google로 다시 보냄), 체크리스트(저장 안 함), 판례 링크(앱이 검색어를 보내지 않음)를 v3 수정안·검토 자료에 반영

## 이용자 IP 신뢰성 (2026-10-06)
- 앱은 X-Forwarded-For를 오른쪽부터 읽도록 고침(왼쪽 값은 이용자가 써 넣을 수 있음)
- Streamlit Community Cloud 앞단 프록시가 이용자가 넣은 값을 지우는지에 대한 공식 문서는 찾지 못함(GitHub 이슈 #12005: `st.context.ip_address`는 프록시 뒤에서 실제 IP를 반영하지 않음)
- 결론: 신뢰 경로 미확인 → IP 전달 기능은 켜지 않음. 로그인 제한이 문제가 되면 우선 Supabase 제한값 소폭 상향을 검토
