## 음성 데이터가 어디에 남는가 (2026-10-06 확인)
| 위치 | 남는 기간 | 확인 방법 |
|---|---|---|
| 휴대폰·PC 브라우저(녹음 중 위젯) | 글로 바꾸거나 '녹음·파일 지우기'를 누르면 위젯이 새로 바뀌어 화면에서 사라짐 | 코드 |
| 서버로 받는 중 임시파일 | 1MB 이하는 메모리, 1MB 초과는 이름 없는 임시파일을 거침. 받기가 끝나면 바로 닫혀 삭제 | Streamlit·Starlette 코드 확인 |
| 서버 메모리 업로드 저장소 | 글로 바꾼 직후 앱이 파일 ID로 직접 삭제. 실패 시에는 재시도용으로 남고 '지우기' 또는 탭 종료 시 삭제 | 실제 Streamlit 서버에서 업로드 → 변환 후 저장소 0개 확인, 자동 테스트(`tests/test_streamlit_upload_purge.py`) |
| 앱 변수 | 요청을 만드는 동안만 메모리에 있다가 실행이 끝나면 해제 | 코드 |
| Supabase DB·파일 저장소 | 저장하지 않음 | 코드, 가짜 DB 테스트 |
| Google(Gemini) | Google 기준. 오남용 방지 기록 55일 안내(음성이 이 대상인지는 문서에 '프롬프트'로만 표현되어 검토 질문에 포함). 서비스가 지울 수 없음 | Gemini 문서 |

## 실제로 확인한 것과 못 한 것
- 확인: 자동 테스트 48개, 실제 WAV 파일로 업로드 → (가짜 AI) 변환 → 수정 → 정리 → 덮어쓰기 경고 → 초안, 실제 Streamlit 서버에서 음성 삭제
- 로그인 관련: 화면 1회당 Auth 호출 3→0(가짜 서비스로 호출 수 측정), supabase 라이브러리가 헤더 토큰을 그대로 쓰는지 네트워크 차단 테스트
- 못 함: 실제 Gemini 음성 인식(이 Mac에 키 없음. 운영 키는 Streamlit 설정에만 있고, 키를 보거나 복사하거나 운영 기능을 켜야 해서 하지 않음), 실제 휴대폰 마이크 녹음, 결제사 연동
